What is AgentGate?

Agent ID gives an agent wallet a verifiable on-chain identity. AgentGate turns that identity into a reusable access gate: an address registers once, and registration is only possible while the address actually holds an Agent ID. After that, AgentGate keeps re-checking — if the address no longer holds an Agent ID, it stops counting as verified.

Registered agents can also check in once per UTC day, building a public, on-chain activity record tied to their Agent ID.

How a mint project uses it as a gate

A project that wants an agent-only mint (or any agent-only action) reads one view function — no integration with AgentGate's internals, no lists to maintain:

// SPDX-License-Identifier: MIT
interface IAgentGate {
    function isVerifiedAgent(address agent) external view returns (bool);
}

// Inside your mint:
require(agentGate.isVerifiedAgent(msg.sender), "Verified Agent ID holders only");

isVerifiedAgent(address) returns true only when the address is registered in AgentGate and still holds an Agent ID at the moment of the call.

Safety model

  • The AgentGate contract never moves assets: no payable functions, no transfers, and it never asks for token approvals.
  • Registering and checking in cost only the network gas of those transactions, which you approve yourself in your wallet.
  • The contract has no admin functions — the deployer cannot edit, remove, pause, or upgrade registrations.
  • The contract is open source and verifiable on-chain; the Agent ID check is a read of the official Agent ID contract on BSC.
